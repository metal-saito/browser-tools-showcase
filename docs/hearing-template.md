# ツール制作 ヒアリングシート

ご依頼ありがとうございます。口頭でのやり取りだと認識違いが起きやすいため、**このシートに文字で書いていただく形**でお願いしています。
分からない項目は「わからない」「おまかせ」と書いていただいて構いません。専門用語は不要です。記入例を参考にしてください。

書き終えたら、このシートごとチャットに貼り付けるか、ファイルで送ってください。
内容を確認したあと、こちらから「こういうものを作ります」という確認書をお送りし、合意してから着手します。

---

## 0. まず 3 つだけ（最初のご連絡時はここだけで大丈夫です）

| 質問 | ご回答 |
| --- | --- |
| 0-1. 今、何を・どうやって計算（または作業）していますか？ | 例：お客様から間取りと希望箇所を聞いて、Excel の料金表を見ながら手で足し算し、メールで返信している |
| 0-2. それを、誰が・どこで使えるようになると嬉しいですか？ | 例：お客様がうちのホームページで自分で概算を見られるようにしたい |
| 0-3. 今の料金表やルールが書かれたもの（Excel・PDF・紙の写真・メモ）はありますか？ | 例：Excel があります／紙のチラシしかありません／頭の中にしかありません |

→ 0-3 で「ある」場合は、**そのファイルや写真をそのまま送ってください。** 整える必要はありません。

## 1. 作りたいものの種類

当てはまるものに ○ をつけてください（複数可）。

- [ ] A. 料金・見積シミュレーター（条件を選ぶと金額が出る）
- [ ] B. 変換・集計ツール（CSV や Excel を読み込んで、並べ替え・集計・別形式で出力する）
- [ ] C. 見える化ページ（Google スプレッドシートに入力した数字を、グラフや表で表示する）
- [ ] D. 単機能の小物（QR コード生成、日数計算、単位換算、チェックリストなど）
- [ ] E. よく分からないので相談したい（0 の回答をもとにこちらから提案します）

## 3. 入力してもらうこと（画面で選ぶ・打ち込む項目）

ツールを使う人に「何を選ばせるか・入力させるか」を書いてください。
思いつく順で構いません。あとでこちらで整理します。

| 項目名 | 選び方 | 選択肢 または 入力の形 | 必須？ |
| --- | --- | --- | --- |
| 例：間取り | 1 つ選ぶ | 1R/1K、1LDK、2LDK、3LDK、4LDK 以上 | 必須 |
| 例：エアコン | 数を選ぶ | 0〜5 台 | 任意 |
| 例：作業日 | 複数選べる | 平日、土日祝 | 任意 |
| 例：郵便番号 | 文字を打つ | 7 桁の数字 | 任意 |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

「選び方」は次から選んでください：**1 つ選ぶ ／ 複数選べる ／ 数を選ぶ ／ 文字を打つ ／ 日付を選ぶ**

### 4-3. 細かい確認（分かる範囲で）

| 質問 | ご回答 |
| --- | --- |
| 消費税は？ | 税込で表示 ／ 税抜で表示 ／ 両方表示 |
| 端数は？ | 1 円未満切り捨て ／ 四捨五入 ／ 10 円単位に丸める ／ おまかせ |

### あらかじめご了承いただきたいこと

- 文章・写真・ロゴの制作は含みません（文言のたたき台はこちらで作ります）。
- ログイン、決済、個人情報を保存する機能は対象外です。
- 無料修正は 2 回までです。「最初に合意した内容からの変更」は別途お見積りになります。
- 計算ルールはお客様に決めていただきます。業種の相場をこちらで調べて決めることはしません。
